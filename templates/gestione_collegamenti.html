Come ottenere il token (una volta sola)
  1. L'account Instagram deve essere professionale (Aziendale o Creator): app Instagram → Impostazioni → Tipo di account.
  2. Vai su developers.facebook.com/apps → Crea app → caso d'uso «Gestisci messaggi e contenuti su Instagram».
  3. Nell'app: Instagram → Configurazione API con login di Instagram → «Aggiungi account» e accedi con l'account Dentalia.
  4. Premi Genera token accanto all'account, copia il token e incollalo qui sotto. Il token generato da lì dura 60 giorni e si rinnova da solo se lo usi.

In alternativa funziona anche un token della Pagina Facebook collegata all'Instagram (con il permesso instagram_content_publish): l'app lo riconosce da sola.

Come ottenere il token (una volta sola)
  1. Apri Graph API Explorer, scegli l'app Dentalia Pubblicazione e «Utente».
  2. Aggiungi le autorizzazioni pages_show_list, pages_manage_posts, pages_read_engagement e premi Generate Access Token (scegli la Pagina Dentalia).
  3. Apri il Debugger del token, incolla il token e premi Estendi token d'accesso: copia il token lungo che compare.
  4. Incollalo qui sotto: l'app trova da sola la Pagina Dentalia e salva il suo token, che non scade.

Come ottenere il token (una volta, poi ogni 60 giorni)
  1. Vai su linkedin.com/developers/apps → Create app; come «LinkedIn Page» indica la pagina Dentalia (devi esserne amministratore) e verifica l'app dalla pagina.
  2. Nella scheda Products richiedi Community Management API (LinkedIn la approva in qualche giorno).
  3. Approvata: Docs and tools → OAuth Token Tools → Create token, spunta w_organization_social e r_organization_social (e rw_organization_admin), accedi e copia il token.
  4. Incollalo qui sotto. L'ID della pagina è il numero nell'indirizzo della pagina admin (linkedin.com/company/12345678/admin): se lo lasci vuoto lo cerco io.
